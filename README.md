# 智慧評語小幫手（Comment Helper）

[![CI and Pages](https://github.com/derliang/comment-helper/actions/workflows/ci.yml/badge.svg)](https://github.com/derliang/comment-helper/actions/workflows/ci.yml)

**版本：v1.4.1**　｜　[開啟評語工作台](https://derliang.github.io/comment-helper/)　｜　[查看發布紀錄](https://github.com/derliang/comment-helper/actions)

以國高中導師期末評語工作為核心：快速匯入班級名單，評量學生的日常表現，生成 42～50 字（含標點）的發展性評語，自動生成且符合硬性規範即可輸出 Excel 或 Word，不需逐筆確認；教師可自由修改。網頁本身可由 GitHub Pages 提供，不必先架設伺服器。預設在瀏覽器內運作，不需要 AI API 金鑰。

## 特色與操作流程

1. 建立學期班級，貼上學生名單或匯入 XLSX、CSV、TXT、DOCX。支援多工作表、舊版欄位、校務系統跨列 Word 報表及已有部分評分的檔案。
2. 垂直學生清單顯示「尚未評／評分中／已評」。點擊姓名展開六向度評分、個別補充資料及即時草稿。
3. 五級量表固定由 5 到 1，綠→黃綠→黃→橙→紅。六向度為日常生活表現、整潔習慣、禮節、班級服務、待人誠信、自律自重。整體星等採等權平均，未完整評分不顯示星等。
4. 一鍵設定單一學生全部分數；全班基準只補未評分欄位，保留已填分數。鍵盤聚焦評分格後按 5～1，選取並跳至下一向度；Shift+Enter 完成評分。批次生成不覆蓋已確認評語。
5. 補充觀察、即時生成、文字編輯、字數與重複檢查、教師確認鎖定。需先解除鎖定才可改評分、學號、觀察或評語。
6. 歷史評語支援匯入、搜尋及核對學號。跨學期以已確認學號連結，不以同座號或同姓名推斷同一學生。重複匯入已核對學號的歷史檔也會去重。
7. 從歷史評語統計教師偏好用語、字數、標點及稱呼方式，教師確認 AI 草稿的人工修改可更新偏好。手動交接可選擇包含經初步去識別的樣本及同一學生過往評語。
8. 正式 Excel／Word 僅匯出已確認且符合硬性檢查的評語；完整 Excel 則供教師內部留存（包括學號、評分、星等、補充觀察與草稿）。
9. 自動儲存、工作位置恢復、JSON 完整備份／還原。標題列、瀏覽器分頁、頁尾皆顯示版本號。

## 現行架構（v0.6.0）

所有智慧評語生成、候選排序、教師風格學習及歷史核對均在瀏覽器內執行，**不連接外部 AI、不需要 API 金鑰**。舊 AI proxy 與測試保留作版本紀錄，已不與正式網頁連動；舊備份還原後同樣停用端點設定。

本機引擎先解析教師明確觀察、正負轉折與近期變化，再依六向度五級程度產生有證據的肯定、分級發展方向及候選，按觀察涵蓋、重複風險、字數與教師風格排序。不捏造低分學生優點或未提供的事蹟；無法理解的文字提示人工覆核。本機規則與統計學習仍不是無限制自然語言理解。

### 手動 AI 交接

評分完整後按「AI 交接／提交準備」，選擇待確認或全班完整評分，可選是否包含姓名及歷史評語。下載一份 Markdown，包含現行規則、六向度各五級、學生 JSON、42～50 字限制、生成、獨立覆評與必要重試、固定 Excel/TSV 欄序。複製簡潔交接命令後自行將檔案上傳給獲授權的 AI。程式不會主動上傳或接收外部服務。歷史原始 Prompt 原文保留，交接指令獨立版本 1.0.0，不沿用已取消的學業向度。

## 個資與安全

- 公開儲存庫不包含任何真實學生名單、歷史評語、備份或金鑰。測試只使用合成資料；過往真實檔案的本機測試僅公布匿名總數。
- 工作資料採瀏覽器本機儲存，未加密、沒有跨裝置同步；清除網站資料會遺失。請定期下載 JSON 備份，不在共用電腦輸入真實學生資訊。
- 本機程式不傳送資料至 AI；手動交接檔預設不含姓名、學號、班名及歷史全文。自由文字仍可能含個資，須經教師審閱並依校方資料政策自行決定是否提交。
- 星等、評分及個人觀察是教師內部紀錄，不放入正式學生評語。歷史評語長度可超過 50 字，但新正式評語硬性限制 42～50 字。

## 開發、測試與發布

```sh
# Node.js 22 與 curl
node --check app.mjs
node --test
bash scripts/build-site.sh
python -m http.server 8000 --directory site
# 開啟 http://localhost:8000
```

`build-site.sh` 下載固定版本的 SheetJS CE 0.20.3 及 JSZip 3.10.1，打包到 `site/vendor`，避免正式網頁執行時從第三方 CDN 載入腳本。建置須能連網。

```sh
# 端到端瀏覽器測試（僅合成學生、真正的 xlsx/docx 檔案）
pip install playwright==1.51.0 openpyxl==3.1.5
python -m playwright install --with-deps chromium
python tests/browser-smoke.py
```

GitHub Pages 以 Actions 為來源；`main` push → Node 測試 → 靜態建置 → Chromium 瀏覽器驗收 → Pages artifact → 部署。伺服器程式與測試檔不納入發布套件。版本常數在 `advanced.mjs`；升級時同步更新 HTML、README 與測試。

## 尚未承諾的功能

獨立雲端資料庫與帳號、跨裝置同步、真正模型微調、校方個資合規審核仍需另行決定。外部 AI 自動串接依新需求停用，不列為待完成；本機教育適切性仍需教師驗收。

### 教師風格版本與本機主題核對

歷史頁面可審核偏好用詞、儲存版本，或以舊版偏好建立新版本而不覆蓋紀錄。已確認的風格會優先參與草稿生成及 AI 上下文；自動統計與人工修訂樣本仍保留。學生同學號歷史評語新增同義觀察主題的本機提醒，僅供人工判斷，不等同語意模型或保證不重複。

本機補充觀察支援明確的守時、整潔、服務、同儕協助、禮節、誠信、生活規範、專注、作業、人際及已提供的學習成果等文字，優先保留具體優點。辨識不到的文字、分數與觀察衝突或多項成長方向會提示人工核對。這是有界限的規則解析，不是任意自然語言理解。

### 舊版 AI 獨立品質驗收與部署（歷史紀錄，不適用 v0.6.0）

v0.3.0 在模型生成之後另外發送品質審查請求，即使未同意提供歷史評語也可核對評分、個別觀察與輸出是否一致。若啟用歷史分享，合併進行選取樣本的語意核對。若服務不支援、網路錯誤或模型仍提出問題，介面會提示教師，不會冒稱通過。此功能增加 API 呼叫量，須由服務提供者計費。

如使用 Docker 主機，可複製 `.env.example` 成 `.env`，在主機私下填寫已授權的模型設定和強存取密碼，執行 `docker compose up -d --build`。服務預設僅發布在主機的 127.0.0.1:8787，再以受信任的 HTTPS 反向代理及存取限制供 Pages 連線。這是部署範本，並非已替使用者建立外部服務。勿將 `.env` 提交 Git。

### 本機風格學習模型

使用歷史教師評語及人工修訂的最終文字，建立字元三連詞頻率分布，搭配教師審核用詞，對候選評語做風格排序。先比較歷史文字相似度，再比較風格適配度，且不從模型直接複製任意歷史文字。未經修改的 AI 草稿即使獲確認，也不自動成為教師風格訓練樣本，以免累積 AI 自我模仿。模型計數保留於瀏覽器，不送往 AI 端點。這是輕量統計學習而非大型模型權重微調。歷史匯入保留可取得的評分、觀察和舊版向度，缺漏仍維持原狀。

五級評量準則的五項既有向度沿用原文件；新增「日常生活表現」的說明為暫定設計，待教師審核。工作台可預覽匯入、手動新增學生及修改未鎖定的基本資料、復原上一筆單人評分、切換精簡／分數／評語顯示、複製正式評語。還原會先驗證備份資料結構，避免以無效資料覆蓋工作。

新版增加具體的領導、傾聽、團體氣氛、挫折與近期進步等觀察辨識，並學習句數、開頭長度、分號與稱呼的統計特徵。這仍是有限規則與統計學習，不能取代真正模型的自然語言理解。歷史同義主題擴充，仍須人工判斷是否為真實持續特質。

### 工作台與名單管理

一般評語核對提醒改為預覽區內的非阻斷文字，教師按確認評語即可記錄已核對，不再重複彈出瀏覽器確認視窗。硬性字數、重複與不宜措辭檢查仍保留。設定頁可切換班級、搜尋、編輯、新增、移除及還原學生；移除保留原評分與評語於本機回收區，仍可備份。Word 採藍色、Excel 採綠色下載按鈕，完整 Excel 採淺綠並明示教師留存。

### v0.5 工作台設計

正式名稱為智慧評語小幫手（Comment Helper）。桌面寬螢幕採左評分、右觀察與評語的雙欄展開介面，窄螢幕維持垂直排列；班級、下載、進度、篩選與學生清單分區。所有既有按鈕、色彩量表、資料鍵及匯出格式維持相容。

### v0.5.1 品質及工作流

本機模式可產生至多三個符合字數及重複硬性檢查的其他寫法；無適合候選時明示。人工編輯的草稿不會被即時或批次生成覆蓋，修改評分後仍提示核對，教師可明確按重新生成。全班品質檢視顯示未完成、待確認、硬性問題及相近樣本，並可跳回學生。歷史比對明細分同一學號、同班及其他歷史資料，分別顯示文字與主題相近程度（非 AI 語意機率）。風格頁新增句段及分號使用統計。備份還原驗證回收區資料結構。正式外部模型仍需授權及實測。

### v0.5.2 個人化與觀察核對（歷史紀錄）

經教師明確允許歷史分享後，AI 範例選取優先使用已有評分且與目前學生相近的教師文字，排除已核對為同一學生的舊評語（該生過往文字仍在避免重複欄位）；不傳送評分樣本的身分。歷史明細區分肯定與成長期待方向，不把相同主題直接當成同義評語。本機對已辨識但未以固定對應語呈現的補充觀察提供非阻斷提示，可能有同義改寫誤報。教師手寫草稿可在變更評分後選擇保留並重新確認。這些屬可解釋的本機規則與範例檢索，仍非完整語意模型。

### v0.6.1 證據與覆評規則

## v0.7.0 現行工作流程（優先於舊版說明）

六向度評分完成後即時生成正式評語，符合硬性規則即可下載，不需逐筆確認。原確認按鈕改為選用的保護功能；原已鎖定資料保留，可解除保護。教師手動修改自動保存，不被批次補齊覆蓋。評分及可下載評語分別統計。設定頁可新增、編輯、停用個人語意規則；舊規則版本保留於備份，內建規則不變。評語版本可查看與復原。全班品質檢查仍提供例外處理。UI 採更緊湊的淺色工作區及雙進度。

GitHub Pages 以 Actions 為來源；`main` push → Node 測試 → 靜態建置 → Chromium 瀏覽器驗收 → Pages artifact → 部署。伺服器程式與測試檔不納入發布套件。版本常數在 `advanced.mjs`；升級時同步更新 HTML、README 與測試。建置時 `scripts/write-version-json.mjs` 會產生 `site/version.json`（版本數字、通道如 beta、發布日＝首次寫入該版號的 commit 之台灣日期），Teacher Hub 工具站每 3 小時讀取它更新卡片版本；CI 需完整歷史（`fetch-depth: 0`），淺層 clone 會直接中止建置。
