# 評語結構與優缺點比重：討論記錄

> 狀態：**討論中，未定案，未實作。** 日期：2026-11-28（台北）。寫給沒看過討論對話的人。屬於「評語生成品質與語感」領域（討論順序第 3 項）；這次只先談了結構與比重。

## 1. 使用者要的目的（原話摘要）

評語結構固定為「**肯定優點＋期待改進缺點**」，兩者比重依學生的星等調整：

- 三顆星以上：優點比重 > 期待改進。
- 三顆星：兩者各一半。
- 小於三顆星：優點比重 < 期待改進。

## 2. 現況（讀 `engine.mjs` 的 `draft()`，未實測）

- 評語長度限制 42～50 字，空間很小。
- 優點取自分數 4 以上的向度（5 分用 `positive[i][0]`，4 分用 `[1]`）；沒有 4 分以上時，才取 3 分向度的基本優點。
- 期待改進取自最低分向度（`gradeGuidance`）；全部 4 分以上時改為「持續發揮所長」類延續語。
- 現在沒有「星等決定兩段比重」的機制，比重只是附帶結果。

## 3. 使用者已回答的決定

| 問題 | 回答 | 備註 |
| --- | --- | --- |
| 「三顆星」指什麼 | **整體平均星等**（畫面上的 ★ 數） | 否決：逐向度各自判斷（整體比重難控制）、平均加最低分向度必入改進（規則較多）。已知風險：平均會掩蓋極端的最弱向度 |
| 比重用什麼量 | **分句數** | 否決：字數比例（50 字內硬湊字數容易不通順） |
| 邊界與極端 | **大於 3 星優點較多、等於 3 星各半、小於 3 星改進較多；5 星與 1 星仍各留一小句另一面** | 否決：5 星／1 星只寫單一面（5 星沒有期許、1 星全是缺點，不適合給家長看） |
| 「等於 3 星」的範圍 | **平均 2.75～3.25** | 否決：2.5～3.5（太寬）、只有正好 3.0（幾乎用不到） |

## 4. 使用者原話的前後矛盾（我的整理，使用者已認可處理方式）

原話「三顆星以上優點較多」與「三顆星各一半」重疊。處理成：大於 3 星優點較多，等於 3 星各半。
