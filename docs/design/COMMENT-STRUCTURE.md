# 評語結構與優缺點比重：討論記錄

> 狀態：**討論中，未定案，未實作。** 日期：2026-11-28（台北）。寫給沒看過討論對話的人。屬於「評語生成品質與語感」領域（討論順序第 3 項）；這次只先談了結構與比重。

## 1. 使用者要的目的（原話摘要）

評語結構固定為「**肯定優點＋期待改進缺點**」，兩者比重依學生的星等調整：

- 三顆星以上：優點比重 > 期待改進。
- 三顆星：兩者各一半。
- 小於三顆星：優點比重 < 期待改進。

## 2. 現況（讀 `engine.mjs` 的 `draft()`，未實測）

- 評語長度限制 42～50 字，空間很小。
- 優點取自分數 4 以上的向度（5 分用 `positive[i][0]`，4 分用 `[1]`）；沒有 4 分以上時，才取 3 分向度的基本優點。
- 期待改進取自最低分向度（`gradeGuidance`）；全部 4 分以上時改為「持續發揮所長」類延續語。
- 現在沒有「星等決定兩段比重」的機制，比重只是附帶結果。

## 7. 引擎與語意庫評估（2026-11-28，我的實測與判斷，使用者尚未對此作決定）

實測方法：在獨立 worktree 用 Node 呼叫 `deepGenerate`（實際走這條），抽樣分數組合；暫時量測檔已刪除。語意庫「是否足夠」是依規模與結構推論，**沒有真實教師觀察語料可驗證**。

| 發現 | 證據 | 與本次決定的關係 |
| --- | --- | --- |
| 全 1 分、全 2 分沒有肯定句 | `111111`、`222222` 只有「仍有發展空間」加期許 | 違反「小於 3 星仍留一小句優點」 |
| 3 分段語法不通 | `333333` 產出「也整潔習慣已有基本表現」 | 需修 |
| 全同分時改進項選取無依據 | `222222` 期許「更主動參與班級事務」 | 需定義全同分的選取規則 |
| 句尾套語重複 | 抽 9 筆中「與同學的相處將更為融洽」3 次 | 影響整班雷同度 |
| 速度不穩 | 單次約 0.2～2 秒，`333333` 達 7.9 秒（可能含首次載入，未在瀏覽器驗證） | 與已決定的「取消 0.9 秒延遲」需回頭核對，需用瀏覽器實測 |
| 語意庫規模 | 內建 67 條規則（不限向度 20、自律自重 12、班級服務 8、禮節 8、日常生活 7、整潔習慣 6、待人誠信 6），以正規表達式比對 | 判斷：不足；缺口需用真實補充觀察語料統計「未辨識」比例才能量化 |

我的建議順序（未經使用者決定）：先加星等比重結構並補全低分肯定句與全同分規則；修 3 分段語法與句尾套語去重；蒐集真實語料量未辨識率再擴充語意庫；速度先在瀏覽器實測再決定是否真的取消延遲。

## 9. 3 星以下的語氣（使用者以問題卡回答，2026-11-28）

| 問題 | 回答 | 否決的選項與原因 |
| --- | --- | --- |
| 改進分句的整體語氣 | **溫和期許，說「期待」不說「不足」** | 否決：具體指出要改的行為（低分學生評語較尖銳）、兩者混用（50 字內容易擠、句子不順） |
| 1～2 星時那一小句肯定 | **取分數最高的向度，寫成具體優點** | 否決：統一用「願意嘗試」類態度語（像套話）、全同分用態度語而有高低差取最高（規則多一條，使用者未選） |
| 是否避免「不」「缺乏」「差」等負面字詞 | **禁止，一律改成正向說法** | 否決：允許「尚待加強」「仍需努力」（可能被家長解讀為批評） |

**全部同分**（例如 `111111`）時沒有「最高分向度」：使用者選**用態度類肯定語，如「願意嘗試」「有進步空間」**。否決：依補充觀察決定（要實作兩條路，老師通常不會逐位寫觀察）、不寫肯定句（違反「1 星仍留一小句肯定」）。

**實作時要注意（我的觀察）**：現行引擎 1 星輸出「仍有發展空間」，「仍有」不含禁用字，但是否有其他語料含「不」「缺乏」需實作時掃描；禁用字清單也需要使用者確認範圍。

## 11. P1、P3 的補充決定（使用者以問題卡回答，2026-11-28）

| 問題 | 回答 | 否決的選項與原因 |
| --- | --- | --- |
| 全同分時「期待改進」選哪個向度 | **依向度固定優先順序選** | 否決：依座號或歷史輪流（缺事實依據，老師可能覺得與學生無關）、不挑單一向度寫整體期許（較空泛）。已知代價：同班全同分學生的改進項會一樣；**優先順序本身尚未定** |
| 禁用負面字詞範圍 | **只禁「不」「缺乏」「差」「無法」等明確負向詞** | 否決：連「仍需」「尚待」「加強」也禁（可用詞變少、評語更易雷同）。清單的完整內容尚未定 |
| 真實語料來源（P3） | **由使用者提供去識別化的觀察句（只留句子、不含姓名）** | 否決：程式內加「匿名匯出未辨識句」功能（屬新功能，需另議）、等 T1 再收（語意庫擴充會延後）。尚未由使用者提供 |

**全同分的向度優先順序**：使用者選**自律自重 → 日常生活 → 整潔 → 禮節 → 班級服務 → 待人誠信**（問題卡上的第一個選項，也是我的建議排法；理由是自律與生活常規是其他向度的基礎，期許較不像批評）。否決：照評分表順序（沒有教育上的理由）。

| 類別 | 語句 | 建議處理（我的建議，使用者尚未確認清單） |
| --- | --- | --- |
| 不穩定／不夠穩定 | 守時習慣仍不穩定、整潔責任的落實仍不穩定、團體規範的遵行仍不穩定、學習責任的落實仍不穩定、人際互動仍不夠穩定、自律習慣仍不夠穩定、守約表現仍不夠穩定、專注的習慣仍不夠穩定、學習習慣仍不夠穩定、學習專注度仍不夠穩定 | 改成「期待更穩定」類 |
