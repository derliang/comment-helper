# 備份與還原：討論記錄

> 狀態：**討論中，未定案，未實作。** 日期：2026-11-28（台北）。寫給沒看過討論對話的人。屬於討論順序第 2 項「匯入匯出與備份」；這次只談了「備份與還原的安全性」，匯入名單與匯出評語格式尚未談。

## 1. 現況（讀 `app.mjs` 的 `backup`／`restore` 處理與 `advanced.mjs` 的 `validBackup`，**未在瀏覽器實測**）

- 備份：手動按鈕，下載完整 JSON（`comment-helper-backup-日期.json`），內含全部班級、學生姓名、評語、歷史；明文，沒有加密。
- 還原：選檔、驗證格式、跳「還原將取代目前本機資料」確認後，**整份取代**；沒有還原前自動保存現況，也沒有合併還原。
- 備份提醒：搜尋程式找不到「多久沒備份」的提醒。
- 驗證：檢查版本為 1、欄位型別、六項分數 1～5、ID 不重複；沒有簽章或校驗碼。
- 資料存在瀏覽器 localStorage；空間滿時自動刪較舊的交接檔記錄；清除網站資料會遺失（README 已提醒）。

## 2. 使用者已回答的決定（問題卡）

| 問題 | 回答 | 否決與備註 |
| --- | --- | --- |
| 還原前是否自動保存現況 | **要，還原前自動下載一份現況備份** | 否決：只在程式內留快照（仍在 localStorage，清資料一起消失、占用有限空間）、維持現狀（選錯檔無法回復）。代價：下載資料夾多一份檔案，下載可能被瀏覽器阻擋 |
| 備份提醒 | **要，標題列顯示「已 N 天未備份」** | 否決：只在大量編輯後提醒（規則較複雜）、不要。**N 的天數尚未定** |
| 備份檔隱私 | **維持明文，只在下載時提醒要保管好** | 否決：密碼保護備份（忘記密碼即無法還原，屬不可回復風險，需另議）、去識別化備份（無法還原完整資料） |

## 3. 我的判斷（使用者未說過）

風險排序：1) 還原選錯檔、目前工作消失（不可回復）；2) 沒有備份提醒；3) 明文含姓名；4) 只能整份取代。這是我的排序。
